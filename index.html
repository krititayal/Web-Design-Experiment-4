LEARNING TO THINK WITH DATA

Before the chart, ask a better question

A useful analysis often starts with a smaller, more precise question than the one we first ask.

By Kriti Tayal · October 11, 2026

NOTES ON PROCESS · 01

When a spreadsheet lands in front of us, it is tempting to start plotting immediately. A quick chart feels like progress. But until we know what we want to understand, even a beautifully labelled graph can leave us with more confusion than insight.

Start with the decision

Imagine a campus club wants to know why fewer students attended its last two events. “What happened to attendance?” is a fair opening, but it can be sharpened. Are we comparing event times, topics, how far ahead the events were announced, or something else?

The question matters because it shapes what information we need. If we only have total headcounts, we can describe the change. We cannot confidently explain its cause. Keeping that distinction in view is a small act of honesty.

Good analysis begins by being clear about what the available information can actually tell us.

Make the data easier to read

A short data dictionary helps: write down what each column means, when it was recorded, and which values are missing. Then inspect a few rows before calculating anything. These simple checks often catch dates stored as text or categories that look similar but are spelled differently.

Share the limits with the result

A chart is part of an explanation, not a substitute for one. Name the measure, include units and a useful time range, and add one sentence about uncertainty or missing information. Readers deserve to know where the evidence is strong and where it runs out.

These habits are useful even in a small class project. They slow the first step a little, then make every step after it easier to explain.
